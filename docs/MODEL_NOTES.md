# 模型试聊记录：我想要怎样的聊天感

这份记录整理自 v5.3 到 v5.4 规划阶段的项目总结，保留当时实际聊天后的主观印象，不是本次重新测试的结果。它记录的是“我和它聊起来是什么感觉”，不是通用能力、性价比或产品推荐。

以下模型和产品名称沿用当时的笔记，未逐一核验官方版本或 API 标识。原始完整对话、统一测试题、提示词和参数没有随这份记录一起归档，因此不把体验差异单独归因于模型。尤其陪伴产品还包含自身的人设、记忆与对话设计，不能直接等同于底层模型。

## 什么会让我觉得“像 AI”

反复试聊后，我在意的并不是它够不够聪明，而是它会不会总沿着同一条路回复：

> 重复我的话 → 分析情绪 → 安慰或提建议 → 再问一个问题。

认真倾诉时，理解和建议当然可以有。但普通闲聊也总是如此，就容易让人觉得自己正在接受访谈，或者每说一句话都需要被分析。像“这种感觉最折磨人”“你是不是……”这样的表达，偶尔出现没什么，一旦反复出现，就会显得很模板化。

我希望小栗可以简单接一句，有自己的想法，偶尔嘴欠但不过分，也能顺着话题自然切换严肃与轻松。不是每句话都要有用，也不用每次靠反问维持对话。

## “有自己”不等于临时编故事

让她像一个有自己生活的朋友，也带来了另一个要求：她分享的过去应该有依据。

例如，我说到向家里要钱时，不希望她为了共情就突然声称自己也有同样的经历。固定背景、已经发生的经历、还没完成的计划，以及没有设定的事情，需要分清。她可以有不知道、没经历过的事，仍然可以接住这段聊天。

这也是后来保留 SQLite 记忆、区分经历和计划，并反复调整聊天提示词的原因：希望她有连续的自己，而不是每次为了迎合眼前的话题换一个过去。

## 这份记录怎么读

“真实感”在这里指交流是否自然、人物是否连贯，以及我是否愿意继续聊，并不是说模型拥有真实情感或独立意识。更自然的表现也不代表它在所有任务上更强。

这些印象有个人口味，也受当时的话题、提示词、上下文和产品设置影响。后续如果继续记录，会尽量写清日期、可确认的版本与设置、具体场景，以及为什么喜欢或不喜欢；涉及私人倾诉的原始聊天不会直接公开。
