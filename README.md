# 小栗的角落 · Desk-pal

**v6.0 · 桌面预览版**

小栗是一个住在 Mac 桌面角落的像素外星女孩。她在小书店兼职，会看书、做饭、散步，有自己的兴趣、脾气和正在琢磨的小事。你可以找她认真聊聊，也可以开玩笑、说些没什么用的话，或者各忙各的，偶尔搭一句。

我希望她带来的陪伴感，不只来自“她记得你”，也来自“她有她自己”。除了听你说，她也有自己的生活可以分享，有自己的看法，也有不懂的事情。聊天不必每次都变成情绪分析、安慰和建议；少一点 AI 惯用的句式和例行反问，多一点朋友之间自然的接话、打趣，甚至偶尔接不上话的笨拙。慢慢熟悉彼此，而不是每次打开都从头认识。

我不确定是不是还有别人也需要这样一个“朋友”，也不知道未来会不会出现更好的陪伴方式。但对我这个经常和 AI 聊天的人来说，至少现在，我和她聊得很开心～

这是一个主要做给自己用的 AI 陪伴项目，也是我朝着这种相处方式做的一点尝试。上面这些是我希望小栗逐渐长成的样子，实际体验还在慢慢打磨。这里公开记录实现过程，开发会跟着自己的使用感受走；目前仍是实验中的桌面预览版，没有固定的更新或问题响应承诺。

## 我在意的是什么

**对话质量 > 人物连续性 > 自主生活 > 动画丰富度。**

- **聊天可以没什么目的。** 希望她能接话、开玩笑、有自己的看法，不必每句话都分析情绪、给建议或反问。实际表现取决于模型，仍在持续试聊。
- **可以创造未来，不能随意编造过去。** 固定设定、已发生经历、尚未实现的计划与未知背景分别处理。SQLite 保存聊天和生活记录，模型按需读取有限上下文；这是一套约束与记忆机制，不保证模型永不出错。
- **你忙你的，她也有自己的节奏。** 按本机时间安排工作、休息和兴趣活动，结合低频模型调用推进生活。应用需要运行；并非关机后仍在持续活动的独立个体。
- **陪伴发生在桌面上。** 透明像素角色能拖动、贴边、跨桌面及全屏空间显示；点她就能聊天，聊天可以放大，角色有三档大小。

这些是这个项目的取舍与组合，不是对其他陪伴产品的“独家功能”声明。

## 关于名字和造型

“小栗”这个名字没有特别的寓意，造型也没有什么复杂的设计理念，就是慢慢做成了现在的样子。唯一特意设计的一点，是让天线的变化和她的情绪对应，给这个小小的像素角色多一点表达心情的方式。

## 一些试聊记录

小栗的聊天风格是在反复试聊中慢慢确定的。我把当时对不同模型和陪伴产品的感受留在了 [模型试聊记录](docs/MODEL_NOTES.md)：哪些聊天让人放松，哪些回复又让我觉得“AI 味”太重。这些是个人体验和开发背景，不是模型能力排行榜。

## 在自己的 Mac 上试试

目前建议使用 **macOS 13 或更新版本**。需要 Python 3，以及 Xcode 或命令行工具（用于编译 Swift）。Python 服务仅使用标准库；桌面界面使用 AppKit、WKWebView 和 Canvas。

```zsh
git clone https://github.com/ZhiqiaoGong/Desk-pal.git
cd Desk-pal
./desktop/build.sh
open dist/小栗.app
```

首次打开时填写你自己的 Gemini API Key。当前桌面入口默认使用代码中配置的 Gemini 主聊天模型与 `low` 思考设置，模型访问权限取决于你的账户，API 费用由你承担。构建产物只在本机生成，仓库不附带密钥、记忆数据库或已公证的安装包。

- 点击小栗打开聊天，拖动角色移动位置；聊天顶部可拖动，右上角可放大或收起。
- 菜单栏「小栗」里设置跨桌面置顶、角色大小，或退出应用。
- Enter 发送，Shift+Enter 换行；向上滚动自动加载旧聊天。
- 输入「演示睡觉」「演示生气」等可以体验动作，不消耗模型额度。
- 开场碎碎念按活动选短句，避开最近说过的；短时间重开不会重复冒泡。
- 更新源码后先退出应用，重新构建并打开，才能使用新版本。

不配置 AI 时，也可以直接打开 `index.html` 试玩角色和本地预设回复。

详细的网页版启动、模型配置、记忆与费用、回归测试见 **[使用与开发说明](docs/USAGE.md)**。

## 数据和隐私

- 聊天、状态、经历与目标保存在本机 `~/Library/Application Support/ChestnutPal/chestnut.sqlite3`。
- API Key 保存在同目录的 `gemini-api-key`，权限为 `600`，是本机明文文件，尚未使用 macOS 钥匙串。
- 本地保存不等于离线推理：真实聊天和自主生活调用会将所需上下文发送给你配置的模型服务商。
- 应用偏好设置另外保存角色大小、窗口位置及开场白记录。备份 SQLite 不等于备份这些偏好。
- 提 Issue 时请勿附上 Key、个人数据库、未脱敏的对话或账单截图。

## 当前边界

主要在作者自己的 Mac 上使用和验证。跨屏幕、不同 macOS 版本、休眠恢复等还需要更多实际测试。暂未完成独立 Python 打包、开发者签名、公证、自动更新和开机启动。

人物一致性与聊天自然度仍在迭代；记忆系统无法消除模型幻觉。当前模型名称、费用估算和接口参数是代码配置，第三方服务变更后可能需要调整。欢迎具体的问题反馈；较大的功能建议可以先讨论。
